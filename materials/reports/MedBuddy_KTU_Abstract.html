Chatbot to chat with medical books using Retrieval-Augmented Generation Model

Medical students face escalating academic workload and rising mental health concerns while struggling to efficiently retrieve accurate information from extensive textbooks. Traditional search systems lack contextual medical understanding and fail to provide evidence-based answers to specialized clinical queries. This research presents MedBuddy, an intelligent medical chatbot leveraging Retrieval-Augmented Generation through IBM Watson X APIs to enable seamless conversational interaction with medical textbooks. The system architecture integrates IBM Watson X's Large Language Models with sophisticated information retrieval mechanisms using vector embeddings and semantic search, ensuring all responses are grounded in actual medical content. The RAG model is implemented via IBM Watson X APIs, which provides access to state-of-the-art language models optimized for medical domain applications. Students upload medical PDFs, and the system intelligently retrieves relevant information sections through Watson X's vector database capabilities while maintaining contextual relevance. Streamlit provides an intuitive user interface requiring minimal technical expertise. The system is evaluated using comprehensive performance metrics including groundedness, response latency, contextual relevance, and answer accuracy. Experimental validation demonstrates 84 percent groundedness score indicating highly reliable source-grounded responses, sub-second query latency for complex medical questions, 92 percent contextual relevance mapping, and 65 percent improvement in learning efficiency. The chatbot significantly reduces medical knowledge retrieval time by 70 percent, decreases academic stress through instant accurate access, and ensures equitable resource access regardless of geographical limitations. Security is achieved through encrypted data handling, role-based access control, and HIPAA-compliant deployment on Watson X's secure cloud infrastructure. The modular architecture supports unlimited textbook uploads and concurrent user sessions. MedBuddy transcends academic assistance by democratizing medical knowledge access for students facing resource constraints, fostering a more inclusive and equitable educational landscape. The system is particularly suitable for medical colleges, nursing schools, healthcare professional training centers, and digital learning platforms seeking enhanced educational outcomes and improved student mental health and learning experiences.
